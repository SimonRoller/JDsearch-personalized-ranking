# JDsearch Personalized Ranking
BT4222 Data Mining project investigating whether user history improves the ranking of product search results on JDsearch.

We compare two LightGBM ranking models:
- **Model A:** 7 query–product, popularity and metadata features.
- **Model B:** The same 7 features plus 23 user-history features.

## Notebook execution order

The notebooks are located in `notebooks/`:

1. EDA and data splitting
2. Feature engineering
3. Baseline model training
4. Personalized model training
5. Model comparison and evaluation
